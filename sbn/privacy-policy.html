SBN 개인정보처리방침

최종 업데이트: 2026년 11월

1. 수집하는 개인정보 및 권한

SBN는 별도의 외부 서버나 데이터베이스를 운영하지 않으며, 사용자의 개인정보를 수집하거나 제3자에게 전송하지 않습니다. 크롬 확장프로그램은 사용자의 명시적 동의 하에 Google OAuth https://www.googleapis.com/auth/drive.file 권한만 사용하여 사용자의 개인 Google Drive 내 SBN 폴더 및 해당 앱으로 생성한 파일에 직접 접근합니다.

2. 데이터 저장 및 동기화

  • 모든 문서, 스프레드시트, 슬라이드, 폴더는 사용자의 개인 Google Drive에만 저장됩니다.
  • 레이아웃 설정, 폴더 순서, 즐겨찾기 목록은 사용자의 Chrome 브라우저 동기화 저장소(chrome.storage.sync)에만 저장됩니다.

3. Google API 사용자 데이터 정책 준수

SBN의 Google API를 통해 수신된 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함하여 Google API 서비스 사용자 데이터 정책을 준수합니다.

Privacy Policy for SBN

Last Updated: November 2026

1. Data Collection & Permissions

SBN does not operate any external servers or databases, and does not collect, store, or share any personal user data with third parties. With the user's explicit consent, the extension uses the minimal Google OAuth scope https://www.googleapis.com/auth/drive.file solely to create, list, rename, search, and organize folders and files inside the user's own Google Drive (SBN folder).

2. Storage & Sync

  • All notes and files remain exclusively in the user's personal Google Drive.
  • UI preferences (layout mode, folder order, pinned file IDs) are stored only in Chrome's built-in chrome.storage.sync.

3. Google API Services User Data Policy

SBN's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
