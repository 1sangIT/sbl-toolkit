# 공개 강의자료

이 폴더에 올린 파일은 강의 라이브 페이지의 자료 탭에 자동으로 표시됩니다.

## 업로드
1. Add file → Upload files를 선택합니다.
2. PDF·PPTX 등 자료를 끌어놓습니다. 파일명은 학습자에게 그대로 표시됩니다.
3. Commit changes로 main 브랜치에 저장합니다.
4. GitHub Pages 배포 완료 후 강의 페이지에서 목록 새로고침을 누릅니다.

## 삭제
해당 파일을 열고 파일 메뉴에서 Delete file을 선택한 다음 변경사항을 저장합니다.
배포 후 목록과 현재 다운로드 경로에서 빠집니다. Git 이력 및 이미 다운로드한 사본은 삭제되지 않습니다.

## 주의
- 누구나 볼 수 있는 공개 자료만 올리세요. 개인정보·비밀번호·미공개 교재를 올리지 마세요.
- 가급적 파일당 10MB 이하로 유지하세요. 브라우저 업로드 한도는 25MiB입니다.
- 하위 폴더 없이 이 폴더에 직접 올리세요.
- 파일명이 점(.) 또는 밑줄(_)로 시작하는 파일, Markdown·HTML 등 웹페이지 파일은 사용하지 마세요.
- 파일 교체 시 같은 이름을 사용하면 이전 링크에 접근하는 사람도 새 파일을 받게 됩니다.
- 이 안내문은 다운로드 자료 목록에 표시되지 않습니다.
